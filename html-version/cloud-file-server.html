Perguntas Frequentes sobre Cloud File Server

Tudo o que você precisa saber antes de migrar os arquivos da sua empresa para a nuvem Sysmax.

Não! O Sysmax Cloud File Server utiliza a tecnologia de sincronização inteligente sob demanda (Smart Sync). Os arquivos aparecem normalmente no Windows Explorer ou macOS Finder com ícones indicativos, mas os dados reais ficam na nuvem, sendo baixados instantaneamente apenas quando você abre o arquivo. Isso poupa espaço no seu SSD e permite trabalhar com terabytes sem sobrecarregar notebooks.
